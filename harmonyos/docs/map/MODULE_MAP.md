## 核心调用链

- 启动：EntryAbility.onCreate → init → Locator.init/initStores → Db.open；加载 SettingsStore 设置全局 dark；窗口加载 Index。
- DI/领域：Locator.repo/source/sync 延迟构建 CourseRepositoryImpl/FuwaiTimetableSource/SyncTimetable；init 合并初始化 Promise。CourseRepository、TimetableSource 是接口，Course/CourseValidation/Grade/Exam 是模型、校验和统计；页面仍直接调用部分 Store，没有完整 ViewModel 层。
- 课表：页面 → Locator.syncAndSave/syncWithCaptcha/syncWithQr → SyncTimetable.run/resumeCaptcha/qrLogin → FuwaiTimetableSource → ZhengfangAuth → 网络；parseTimetable 转模型；SyncTimetable.commit → CourseRepositoryImpl.replaceAll → Db.transaction → CourseDao.clear/insertAll。Locator.persist 保存学期、资料并启动后台成绩。
- 认证：ZhengfangAuth 处理正方直登、门户、扫码与业务读取；CasSession.prepare/attempt、CasTicket.follow/mint 处理 CAS；WecomQrLogin.start/poll/exchange 保留扫码会话；RsaPublicKey.encrypt 与 casEncrypt 做公钥加密。SessionStore 的持久会话与 CookieJar 的请求容器不同。
- 网络：HttpClient.get/postForm/getBytes 使用 CookieJar；RawHttp 提供底层传输；具体协议边界见 API_MAP。
- 成绩：Locator.syncGrades/gradesInBackground → GradeSync.quiet/run → SchoolTraffic.run → doRun/collect → ZhengfangAuth.fetchGrades → GradeAdapter.parse → summarize → GradeCacheStore.save。考试页使用 fetchExams → ExamAdapter.parse，另有 Web 页面路径。
- 本地：Db/CourseDao 存课程课表；TimetableStateStore 管账号/课表对应学期及活动表；PeriodStore 管节次；CredentialStore/SessionStore → SecretStore 管凭据与会话；GradeCacheStore 管快照；ProfileStore/AvatarStore/SettingsStore/ShareCodeStore/FeedbackStore 分管资料、头像、设置、分享、待发反馈。
- 分享/反馈：页面 → ShareApi；FeedbackDelivery.send/flush → FeedbackStore + uploadFeedback。服务端是 Node 原生 HTTP。
- 卡片：EntryFormAbility.onAddForm/onUpdateForm → buildPayload → Db/CourseDao + PeriodStore + TimetableStateStore → buildDayLines；Index.loadCourses → WidgetRefresh.update → formProvider.updateForm；DayCard 展示绑定数据。
- 工具：TermCalendar 算学期周日期；SchoolCalendar 提供校历；CourseFormat/NextClass/ShareText 管格式、下一节课及文字分享；CalendarExport 与 refreshOwnedReminders 管系统日历/提醒；AccountScope/SchoolTraffic/SerialQueue 管生命周期与串行；PrivateLog 管日志；Tokens 为设计常量。
- UI：pages 是实际页面，ui/components 是共享组件。仅 .gitkeep 的 app/bootstrap/router/store、ui/pages/theme/viewmodel、common/error/logger/utils、network/cookie/interceptor、entryformability 不代表已实现；实际卡片 Ability 在 widget。MockData 被旧演示课程清理引用，不是首次启动种子。ProfilePage.ets.corrupt.bak 不作为实现来源。
