这是什么

福小外把一学期的课表收进手机：周视图一屏看全一周，日视图只看今天；课程可以手动录入，也可以用一个口令和同学互换课表。 你可以把课表导出到系统日历、设置上课提醒，或者在桌面放一张「今天的课」卡片。课表与成绩主要保存在本机，分享、反馈和登录统计按隐私政策处理。

主要功能

课表查看

周视图与日视图，左右切换一周、上下切换学期，支持深色模式。

手动添加课程

课程名、教师、教室、校区、星期、节次、周次与颜色，一次填完。

口令分享与导入

把课表压成一个 32 位口令发给同学，对方粘贴即可导入，口令 30 天有效。

校历

按学期展示教学周与节假日，方便对照当前是第几周。

成绩查询

登录你所在学校的教务系统后查看成绩、学分与绩点统计。

考试安排

汇总本学期考试时间与地点，和课表放在同一处。

上课提醒

按本周课表生成提醒，可提前 5/10/15/30 分钟；也可导出到系统日历。

桌面小组件

「今天的课」卡片放在桌面，不用打开应用也能看到下一节课。

数据在哪里

课表、成绩、个人资料与设置主要保存在应用私有目录；成功登录后，学号会发送至统计服务计算 HMAC 去重，仅保存摘要、用户 ID 和首次注册时间； 只有你主动点「分享课表」时，才会把课表快照临时存到本站的口令服务，口令 30 天后自动失效； 只有你主动点「提交反馈」时，才会把反馈文字、你填写的联系方式与所附图片发到本站。

本站只用于展示应用信息。 本站不提供安装包下载，也不做注册登录、不做推广与交易。 应用通过华为应用市场发布与更新，安装请前往应用市场搜索「福小外」。
