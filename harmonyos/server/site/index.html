这是什么

福小外把一学期的课表收进手机：周视图一屏看全一周，日视图只看今天；课程可以手动录入，也可以用一个口令和同学互换课表。 你可以把课表导出到系统日历、设置上课提醒，或者在桌面放一张「今天的课」卡片。所有信息都保存在本机，卸载即清空。

主要功能

课表查看

周视图与日视图，左右切换一周、上下切换学期，支持深色模式。

手动添加课程

课程名、教师、教室、校区、星期、节次、周次与颜色，一次填完。

口令分享与导入

把课表压成一个 32 位口令发给同学，对方粘贴即可导入，口令 30 天有效。

校历

按学期展示教学周与节假日，方便对照当前是第几周。

成绩查询

登录你所在学校的教务系统后查看成绩、学分与绩点统计。

考试安排

汇总本学期考试时间与地点，和课表放在同一处。

上课提醒

按本周课表生成提醒，可提前 5/10/15/30 分钟；也可导出到系统日历。

桌面小组件

「今天的课」卡片放在桌面，不用打开应用也能看到下一节课。

平台支持

福小外现在是双端：鸿蒙原生版与安卓版共用同一个包名、同一套口令分享协议和同一套后端接口，两端之间可以互相导入课表。

数据在哪里

课表、成绩、个人资料与设置全部保存在应用私有目录，不上传到本站； 只有你主动点「分享课表」时，才会把课表快照临时存到本站的口令服务，口令 30 天后自动失效； 只有你主动点「提交反馈」时，才会把反馈文字、你填写的联系方式与所附图片发到本站。 登录教务系统用的账号口令在设备上加密保存：鸿蒙端用系统 HUKS 托管密钥，安卓端用 Android Keystore 包装的 AES 密钥，都不会明文落盘。

本站只用于展示应用信息。 本站不提供安装包下载，也不做注册登录、不做推广与交易。 鸿蒙版通过华为应用市场发布与更新；安卓版 0.1.1 目前是验收包，只放在 GitHub Releases，尚未上架任何应用商店。

权限说明

权限用途是否可拒绝
网络登录学校教务系统、口令分享与提交反馈拒绝后无法同步课表与成绩
通知 / 提醒代理上课提醒可拒绝，仅影响提醒
日历（读、写）把课表导出到系统日历，写入前先读以避免重复可拒绝，仅影响导出
相册与文件（按需）更换头像、反馈时附加截图，由系统选择器单选可拒绝，仅影响选图

安卓端权限与上表基本一致：网络、通知（上课提醒）、日历读写（导出课表）、图片选择（更换头像与反馈附图，Android 13 起使用系统照片选择器，不申请整个存储空间）。
