# 验收与证据清单

这是完整正式验收门禁；本轮已做的代码与局部验证见VERIFICATION_REPORT.md。组合项目未全部满足时保持未勾选，不把单元测试通过等同正式验收。

每条证据填写：日期/时区、平台及设备系统、源码SHA/未提交差异、包SHA256、服务版本、脱敏数据版本、命令与退出码或人工步骤、实际结果、证据路径、风险及回滚点。不将真实用户数据或秘密写入本表。

## 批次1：冻结与恢复

- [ ] 真实源码/构建工具已定位，复现当前版本，发布身份与证书链已核对。
- [ ] 所有现有服务路由/方法/成功响应及旧可选字段冻结；原发布客户端样本可用。
- [ ] 固定数据下全部页面和导航、登录/反馈成功动画有截图/录像。
- [ ] 登录、课表、成绩、分享、反馈fixture完成脱敏复查；请求关联仍可验证。
- [ ] 数据备份隔离恢复通过，数量、归属、设置及历史口令核对一致。

## 批次2：安全边界

- [ ] null、数组/对象混淆、坏JSON、缺必填、超限字符串/课程/图片、负数/NaN等内部调用、越界节次/周次返回明确错误；随后正常请求成功。
- [ ] 旧正常请求状态码、稳定字段和行为不变；新增默认值不改变旧可选字段含义。
- [ ] `<img onerror=...>`、闭合标签、引号、Unicode特殊字符在学期/联系方式/反馈等均按文字显示，无额外节点或脚本执行。
- [ ] 非法图片URL/路径被拒，CSP下后台列表、分页、详情、已读、删除、探针、告警、审计及主题/动画正常。
- [ ] 无生产配置拒启；发布日志、异常、请求URL和样本无秘密；签名材料未更换。

## 批次3：迁移、事务与账号

- [ ] 明文迁移在加密写、flush、解密验证、版本切换、删旧值各点故障/重启可重试；失败保留可用原数据，不记录明文。
- [ ] 缺密钥、密文损坏、错误账号AAD明确失败；升级后同发布身份可读取，禁止静默明文降级。
- [ ] 同courseId在不同表/账号并存；原Course.id不变；旧remove(id)歧义不批量删；迁移前后表/课数与归属一致。
- [ ] replaceAll第N条插入抛错、事务提交前杀进程，恢复后全旧或全新；删除表/多写修改同样验证。
- [ ] 同步、手动编辑、导入并发按明确队列顺序提交；失败队列可继续处理后续请求。
- [ ] A同步中切B/退出、成绩在途切号、扫码取消、验证码失败、退出后重入，旧成功与旧失败回调均不覆盖新账号UI/持久化。
- [ ] 清理入口范围明确；日历拒权/删除失败不阻止其他清理，可重试；待发图片不被普通缓存清理误删；本地退出不宣称云端删除。
- [ ] 整表覆盖快照可恢复，课程与元数据一致，未自动合并手动修改。

## 批次4：业务与系统对象

- [ ] 多表不同学期：首页、分享、卡片、提醒、导出读取同一元数据；旧表默认配置有来源，无月份猜测。
- [ ] 成绩跨学期/多页、重复页、截断、超过保护上限、网络超时、会话过期与真实空成绩区分；单学期失败保留旧完整缓存和更新时间。
- [ ] 反馈200保存才已发送；429秒/HTTP日期延迟持久化，超时/5xx/重启可重试；切IP重试无重复或明确记录幂等边界。
- [ ] 图片编码失败明确提示；3张图JSON实际UTF-8字节越界拒绝，不能静默丢图；成功清临时文件，满队列不裁掉未发项。
- [ ] 提醒/日历部分成功再重试，重复导出和账号切换不重复、不删除其他应用对象；系统写后登记前故障有对账恢复。
- [ ] 卡片扩展独立冷启动、退出后及多账号切换均无旧数据残留；设备权限与配额限制如实提示。

## 批次5：网络与运维

- [ ] 截断Content-Length、坏chunk、压缩解码超限、慢响应/超时、相对/跨域跳转、取消及Cookie作用域/过期均有回归。
- [ ] 教务直登、CAS、验证码、扫码及课表/成绩/考试全部通过同一协议样本，再做授权账号真实设备验证。
- [ ] 官方HTTPS/安全入口核验结果留证；未解决时不宣称学校链路加密，不发送学校凭据到自建服务。
- [ ] 磁盘满、只读目录、rename失败、重启、并发容量临界、缓存过期、孤图/历史清理不损坏已有JSON；无半保存成功响应。
- [ ] 校园共享出口的多用户正常请求可用；伪造代理头不能绕限流；只有指定代理头被信任。
- [ ] 告警、备份及隔离恢复演练通过，单进程文件存储边界明确。

## 批次6：发布

- [ ] 固定设备数据截图逐页比较，必要文字/错误结果差异逐项解释；动画及按钮位置无未解释变化。
- [ ] 原发布版本升级保留数据；原签名身份覆盖安装成功；旧客户端访问升级后后端正常。
- [ ] 正式构建/验包/安装记录和源码/包哈希齐全；模拟器通过不替代实体设备和商店验证。
- [ ] 每批独立回滚点，迁移程序与数据配对恢复；系统对象和发布后新增云端数据已对账。

只有上述门禁与证据相符，才可在记录中将对应任务标为“已验收”。
