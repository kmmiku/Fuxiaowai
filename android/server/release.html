安装说明首次安装需允许「未知来源」

  1. 点上面的按钮下载 APK 文件（{{SIZE}}，约十几秒）。
  2. 下载完成后点开文件，系统会提示「禁止安装未知应用」，点设置 → 允许这个来源安装，再返回。
  3. 安装完成后打开「福小外」，用学号 + 教务密码导入课表就能用了。

使用前须知

需要访问校内教务：课表、成绩、考试都从 jw.fzfu.edu.cn 读取，校外请先连学校 VPN，否则只能看手动添加的课。
账号只用于登录教务：学号密码保存在你自己的手机上，只发给教务系统，不经过任何第三方服务器。
个人开发：本应用由学生个人开发，与学校官方无关；数据以教务系统为准。
