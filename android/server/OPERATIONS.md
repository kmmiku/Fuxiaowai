# 独立后端副本运维说明

本目录来自同日鸿蒙工作区共享服务源码并补充加固，仅在本地临时数据根测试，未部署生产。实际线上版本与本目录不同；不能直接覆盖线上server.js。后台v2的历史交付记录仍位于原鸿蒙docs/admin-console-20261114.md，本目录不复用其含真实清空反馈动作的部署脚本。

运行Node22或更高版本。管理员凭据通过运行环境注入；缺配置拒启，生产环境拒绝CHANGE_ME占位符。模板fxw.env.example不含真实密码，不要将真实环境文件或签名材料提交Git。

- FXW_ROOT指定受限数据目录；FXW_BIND默认127.0.0.1，FXW_PORT默认8080。
- server/server.js保持CommonJS，由本目录package.json声明，避免继承Android根ESM模式。
- nginx.conf.example只用于既有HTTPS配置内的反代片段，覆盖不可信IP头；后端只在指定回环代理模式信任该头。管理员Basic认证必须位于HTTPS之后。
- 单进程、单数据目录；不支持多个服务实例同时写相同文件。JSON与图片不构成跨文件事务，失败清理和保留期仅提供恢复机制。
- 票据默认30天，反馈及图片默认365天；孤图按保留期清理。统计缓存失效，容量索引包含在途写入；磁盘不足/并发满返回错误，不伪报保存成功。
- 新反馈幂等键为稳定requestId散列，与IP无关，并校验内容指纹；24小时窗口，重启从JSON恢复。旧格式requestKey兼容同IP重试，原始requestId不在旧文件中，无法凭空恢复其跨IP关联。
- 临时文件0600，写入/fsync后rename；Linux同步目录。原JSON字段保留，新termMetadata/requestFingerprint是可选扩展。突然断电、多文件协调和外部磁盘占用仍需环境故障演练。
- 告警/审计的原有管理扩展保持；管理页面使用textContent，CSP允许实际同源脚本/样式/图片和动态样式属性。不要将用户文字插入innerHTML。

发布前须核对生产匹配源码、备份与恢复演练、正常/异常API、旧客户端、旧口令哈希和监控；发布计划获得明确授权后再执行。回滚程序与数据须配对，保全发布后新增反馈/口令；不能为回滚后台UI覆盖tickets。
